房屋租赁系统 后端API接口总览（用于APP对接）
更新时间：2026-03-09

==================================================
一、基础信息
==================================================
1) 本地开发基地址
- http://127.0.0.1:5000

2) API前缀
- /api

3) 认证方式
- 绝大多数接口使用 Bearer Token
- 请求头：
  Authorization: Bearer <token>

4) Token获取
- 通过 POST /api/login 获取 token

5) 响应约定
- 成功通常返回 200/201 + JSON
- 失败返回 4xx/5xx + JSON:
  {
    "error": "错误信息"
  }

6) 续期响应头（仅 token_required 装饰器接口）
- X-Refreshed-Token
- X-Token-Expires

7) 未鉴权接口
- POST /api/login
- POST /api/forgot-password
- 采购模块全部接口：/api/procurements*

二、认证模块 Auth
==================================================
[1] 登录
POST /api/login
请求体(JSON):
{
  "username": "admin",
  "password": "123456"
}
成功响应:
{
  "token": "...",
  "username": "admin",
  "full_name": "管理员",
  "expires": "..."
}

[2] 忘记密码
POST /api/forgot-password
请求体(JSON):
{
  "username": "admin",
  "answer": "密保答案",
  "new_password": "新密码"
}
成功响应:
{
  "message": "密码重置成功"
}

[3] 校验令牌
GET /api/verify-token
请求头: Authorization: Bearer <token>
成功响应:
{
  "message": "令牌有效"
}

[4] 修改密码
POST /api/change-password
请求头: Authorization: Bearer <token>
请求体(JSON):
{
  "old_password": "旧密码",
  "new_password": "新密码"
}
成功响应:
{
  "message": "密码修改成功"
}

==================================================
十四、对接建议（APP）
==================================================
1) 先调用 /api/login，拿到 token 后统一加 Authorization 头
2) 对 token_required 接口，若响应头含 X-Refreshed-Token，建议更新本地token
3) 上传图片字段（如库房 image）使用 Base64 DataURL 最方便
4) 导出接口 /api/system/export 返回ZIP文件流，APP需走下载逻辑
5) 当前采购模块未鉴权，如需上线建议后端补齐鉴权
